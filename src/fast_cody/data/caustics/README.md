# Caustics Textures

This folder contains caustics texture files for underwater visual effects.

## Usage

Access caustics textures in your code using:

```python
import fast_cody as fc

caustics_path = fc.get_data("./caustics/your_caustics_texture.png")
```

## File Organization

- Place caustics texture files (`.png`, `.jpg`, etc.) directly in this folder
- Use descriptive names like `caustics_underwater_01.png`, `caustics_sunlight.png`, etc.
